PÁGINA II

Instrucciones de Uso

✦ ✦ ✦

Para dar uso a la herramienta se debe seguir los siguientes pasos:

  1. Contar con el URL a analizar (Ej. https://www.ejemplo.com).
  2. Pegar el URL en la barra llamada “Ingresa la dirección web para analizar…”.
  3. Presionar el botón “Analizar Fuente”.
  4. Una vez analizado el URL, se podrá ver la información relevante de la fuente analizada.
Importante: la procedencia del URL debe corresponder a páginas de tipo noticias, blogs, corporativas o enciclopedias. Cualquier URL que no pertenezca a estas categorías no podrá realizar el respectivo análisis.

PÁGINA IV

Instrucciones de Uso

✦ ✦ ✦

Para dar uso a la herramienta se debe seguir los siguientes pasos:

  1. Contar con el documento PDF descargado en tu equipo.
  2. Puedes subir el documento de dos formas: arrastrándolo hacia la sección “Seleccionar un PDF para analizar” o presionando esa misma opción para abrir el explorador de archivos.
  3. Presionar el botón “Analizar Documento”.
  4. Para ver la información se debe presionar el botón “Detalles”.
Importante: este análisis no constituye una prueba definitiva de autoría mediante IA. Es un análisis heurístico basado en distintos patrones observables y comprobables en el contenido.
